计划：我们一起做一个复杂任务，用于帮我重复执行一些测试案例，
准备工作：请你连上 Chrome 浏览器，打开doubao.com，在doubao.com中发送指令时需要使用 Enter 键
检查：
左下角是否有已经登录的用户名
检查是否有“表格处理”功能，如果没有，点击更多看里面是否有

如果检查工作都成功通过，就开始执行任务

访问本项目的 task-excel 文件夹，其中每个子文件夹(如task1)为一个单独任务
进入每个文件夹，执行其中task.md中要求的任务（可并行）
对每个文件夹里任务的结果，按其task.md要求检查，给1分或者不给分
当完成所有文件夹的任务后，给出一个总成绩和执行得分/不得分的明细和不得分理由

注意：
1. 避免直接用 JS 设置 textContent ，会破坏了 React 的内部状态，导致键盘输入失效
2. 当云盘文件附加成功后，输入框上方会自动出现两个"建议操作"快捷按钮——"详细分析数据，生成分析报告 →" 和 "根据数据绘制三张可视化图表 →" 不要误触他们
